# Tài liệu Private dùng phát triển

[Hợp đồng đầy đủ có dữ liệu demo](manulife-demo-full-v1/README.md) là bản nguồn thật đã khử định danh, được người dùng cho phép đưa vào Git ngày 03/11/2026. Đây là ngoại lệ riêng, không thay quy tắc mặc định chỉ dùng dữ liệu sinh hoàn toàn giả lập.

Private là phạm vi truy cập trong ứng dụng, không có nghĩa file tự được cấp quyền vì nằm trong repo. Core vẫn phải cấp scope và phiên bản. Chưa nạp bản này vào database hoặc retrieval.

Không tự thêm hồ sơ thật, PDF, ảnh, bản thô, dump, chunks hoặc embeddings vào đây.
